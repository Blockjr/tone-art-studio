# Tone Art Studio - Windows installer build

This repository exists for one reason: to let a Windows runner compile
`ToneArtStudioSetup-0.1.0.exe` (the JUCE host, the Tone Art Virtual ASIO driver
and the Tone Art Gate VST3) and publish it as a release asset.

It needs `Tone-Art-Studio-0.1.0-source.zip` in the repository root. Upload that
file here (Add file -> Upload files), and the `build-windows` workflow does the rest.
